# Mask Remote

A one-page Web Bluetooth controller for LED masks that use the "Shining Mask" app. It handles brightness, built-in animations and faces, party mode (random cycling), scrolling text, and saved custom images.

Open https://chrishaasp3.github.io/mask-remote/ in Chrome on Android (or Bluefy on iPhone) and tap **Connect**.

Protocol credit: [GoneUp/mask-go](https://github.com/GoneUp/mask-go), [BrickCraftDream/Shining-Mask-stuff](https://github.com/BrickCraftDream/Shining-Mask-stuff), [shawnrancatore/shining-mask](https://github.com/shawnrancatore/shining-mask), [BishopFox/shining-mask](https://github.com/BishopFox/shining-mask).
